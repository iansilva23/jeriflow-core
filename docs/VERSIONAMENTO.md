# Versionamento

Este checkpoint é um projeto novo, separado do V5.16.
A conta GitHub iansilva23 foi conectada em 17/09/2026. O responsável criou
o repositório privado iansilva23/jeriflow-core; a instalação do conector e as
permissões de leitura/escrita foram confirmadas nessa data.
O ZIP contém o código e lockfile, não node_modules, builds nem credenciais.

Ao colocar o projeto em repositório privado, revisar arquivos antes do primeiro
push. O workflow incluído é uma configuração preparada, não uma execução
comprovada no GitHub. Tem início manual, tempo máximo de 20 minutos e armazena
somente o relatório de verificação por três dias. Ele falha para alertas a partir
de nível baixo e também verifica instalação, código, rotas, bundles e infraestrutura.

A entrega anterior registrou a preservação do checkpoint a8c21a0 antes de
retirar as tentativas redundantes de override. Na continuação de 16/09/2026,
a pasta encontrada na sessão estava desatualizada. O pacote entregue foi recuperado
em uma pasta separada, preservando a pasta antiga. A nova cópia tem um histórico
Git local iniciado no código recuperado; o ZIP não contém o histórico Git anterior.
Os pacotes entregues anteriormente permanecem recuperáveis pelo histórico de versões.

As regras de branch, revisão e backup remoto precisarão ser habilitadas após
a criação do repositório privado e a confirmação de acesso ao projeto. Não compartilhar
senhas ou tokens no chat. Só autorizar conexões pelos mecanismos oficiais.
